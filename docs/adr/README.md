# Architecture Decision Records

Lightweight memory of *why* the architecture looks the way it does.
MADR-flavored, numbered, immutable once `accepted` — substantive changes
ship as a new ADR that supersedes the old one (`Status: superseded by NNNN`).
Created via `/adr-new`; see `template.md` in the claude-leverage plugin for
the section layout.
